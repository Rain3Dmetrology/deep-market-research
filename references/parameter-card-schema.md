# 研究参数卡 · 结构化 Schema（dmr 唯一权威）

> **单一事实源（single source of truth）**：本文件是「研究参数卡」字段定义的**唯一权威**。
> - dmr §三-B 的研究参数卡以本 schema 为准（不再在 SKILL.md 内重复列字段表）。
> - 调研分析专家团队（`research-analytics-team-team-lead.md` 的《研究参数卡》）字段定义以本 schema 为准。
> - research-orchestrator 的 `run-manifest.json`「参数卡快照」须与本 schema 同构。
>
> 目的：把跨阶段共享上下文从「自由散文」升级为**可机检的结构化卡片**，供 `scripts/validate_param_card.py` 在入口（Step 0 / Phase 1 启动前）做前置校验，杜绝缺字段、来源池缺项、层级/日期格式错误。
>
> **零依赖纪律**：卡片用受限 YAML 子集书写（见下方「格式规范」），`validate_param_card.py` 用**纯标准库正则解析**，不引入 pyyaml 等第三方包，守住 dmr 平台无关护城河。

---

## 一、字段定义

### 必含字段（缺任一 → 校验 FAIL）
| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `课题` | 字符串 | 一句话描述调研主题 | 工业AI 3D视觉测量竞争格局 |
| `范围` | 块（见下） | 地理/时间/实体集/输出形态；至少含 1 个非空子字段，建议含 `时间` | 见下 |
| `实体清单` | 字符串列表 | 竞品/公司/技术列表，非空 | `- 奥普特` |
| `已收集来源池` | 条目列表（见下） | **强制字段**，跨阶段复用唯一证据入口；可为空列表（初始），但字段必须存在 | 见下 |

### 推荐字段（缺 → 校验 WARN，不 FAIL）
| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `决策用途` | 字符串 | 用户要拿结论做什么（投资决策/竞品对位/技术选型…） | 投资决策参考 |
| `模板` | 枚举 | A/B/C/D/E（与 dmr 模板选择规则一致） | C |
| `状态` | 枚举 | drafting/collecting/adjudicating/assembling | collecting |
| `语言` | 枚举 | 中文/英文/双语 | 双语 |
| `查询类型` | 枚举 | 快版/标准/深度 | 标准 |
| `验收标准` | 字符串列表 | **plan-first**：Step 0 产出的可验证目标，每条含度量锚点；终稿对抗审计与 lint 自检逐条对照。配套终止条件三态（达标即停/预算耗尽即停/最多 N 轮）写在卡外 prose，不设字段。**假设失效**：调研中核心前置假设被证伪（实体消亡/市场结构变化）时，达标即停不适用——显式披露假设失效并复用介入窗口请用户重定界，不新增第四态 | `- 市场规模测算误差≤15%` |

### `范围` 子字段（块内）
| 子字段 | 说明 | 示例 |
|--------|------|------|
| `地理` | 调研地理范围 | 中国 |
| `时间` | 时间范围（建议含，用于时效 critic） | 2024-2026 |
| `实体集` | 竞品/公司/技术集合 | 奥普特/凌云光 |
| `输出形态` | 报告/简报/监测… | 报告 |

### `已收集来源池` 条目子字段（每条必须含全部 5 项）
| 子字段 | 说明 | 约束 |
|--------|------|------|
| `实体` | 关联实体 | 非空 |
| `源URL` | 来源 URL 或 DOI | 非空（URL/DOI 均可） |
| `层级` | 源分级 | **必须 ∈ {T1,T2,T3,T4}** |
| `日期` | 采集/发布日期 | **格式 YYYY / YYYY-MM / YYYY-MM-DD** |
| `置信` | 置信标签 | 推荐 ∈ {Confirmed,Corroborated,Single-source,Unverified}；非集合内值 → WARN |

> 「来源池跨阶段复用」机制要求：各阶段（Phase 1–5）优先消耗池中证据，新采集源必须回写此池（实体/源URL/层级/日期/置信），后续裁决与汇编环节只从此池取数。

## 二、格式规范（受限 YAML 子集，可被 validate_param_card.py 解析）

- 缩进：2 空格一级；**禁止 Tab**。
- 顶层字段缩进 0；`范围`/`已收集来源池` 等块的下级缩进 2；来源池条目内字段缩进 4。
- 列表项以 `- ` 开头（实体清单缩进 2；来源池条目缩进 2，其内字段缩进 4）。
- 注释以 `#` 起头（整行）；内联注释不支持。
- 标量：普通文本、单/双引号均可；布尔/数字按字符串处理。

### 规范样例（可作为模板直接复制）
```yaml
课题: 工业AI 3D视觉测量竞争格局
决策用途: 投资决策参考
模板: C
状态: collecting
语言: 双语
查询类型: 标准
验收标准:
  - 市场规模测算误差≤15%（top-down×bottom-up 双法交叉）
  - 核心玩家每家至少 2 个独立 Tier1-3 源
  - 竞品关键参数每条 >=3 独立源（规则 18）
范围:
  地理: 中国
  时间: 2024-2026
  实体集: 奥普特/凌云光
  输出形态: 报告
实体清单:
  - 奥普特
  - 凌云光
已收集来源池:
  - 实体: 奥普特
    源URL: https://example.com/opt/ir
    层级: T1
    日期: 2025-03
    置信: Confirmed
  - 实体: 凌云光
    源URL: https://example.com/lingyun/report
    层级: T2
    日期: 2025-05
    置信: Corroborated
```

## 三、机检（validate_param_card.py）

```bash
python scripts/validate_param_card.py <卡片.yaml> [--strict] [--json]
```

- 退出码：0=通过（无 FAIL；WARN 不致命除非 --strict）/ 1=未通过 / 2=用法或解析错误。
- 校验项：R0 必含字段 / R1 范围非空 / R2 实体清单非空 / R3 已收集来源池条目完整性 / R4 层级∈T1-T4 / R5 日期格式 / R6 置信标签（WARN 级）。
- `验收标准`（推荐字段）：校验器不做内容规则校验（R0–R6 不变），含该字段的卡片照常 PASS（未知字段不拒绝）。
- 覆盖率：来源池条目完整率（完整条目数 / 条目总数）。
- 脚本缺失或环境无 Python → 跳过，绝不阻断 dmr 主管线。
